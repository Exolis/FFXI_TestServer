# LandSandBoat Contributing Guidelines

## License
- GNU General Public License v3.0
- No AGPLv3 or more restrictive licenses accepted

## General Rules
- No support for out-of-date clients or client modification
- No piracy support of any kind
- Cite sources in code comments or commit messages (PR descriptions get lost over time)
- Meaningful commit messages; amend/rebase before pushing
- Credit others using `--author` or `Co-Authored-By:` when committing on their behalf

## Workflow
- Ask questions early rather than investing time into work that may need rewriting
- Submit early and often over monolithic PRs
- For complex features, submit PRs for each smaller functional aspect as it works
- Leave PRs alone after submission unless fixing bugs or addressing feedback
- Open as draft if pushing in-progress work for early review
- Exploitable issues should be reported privately to staff before public disclosure

## Pull Request Rules
- All contributions via pull requests (no Discord-submitted fixes)
- Fill out all templated checkboxes in PR body
- Test your code before submitting
- Address all staff feedback before merge
- Use PR descriptions for context, but put lasting documentation in code comments

## Commit Practices
- Atomic commits: one logical change per commit
- Descriptive messages explaining what and why (not just what files changed)
- Separate formatting/style changes from functional changes
- Squash/rebase fixup commits before final push when appropriate
